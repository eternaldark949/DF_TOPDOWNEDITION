# Body proportions — pending feedback

These tables use the actual game renderer and compare current/proposed isolated parts beside standing, walking and aiming bodies. Flat palette, joints and pose fixtures match. The proposed contours are not applied to the playable game; hair, outfit changes and new gradients are deferred.

- [Female table](DFAB-Body-Proportions-Female.png)
- [Male table](DFAB-Body-Proportions-Male.png)
- `body-shape-preview-edits.json` records the scratch renderer edits and shape specification. It is review data, not an automatic gameplay patch.

The full session ZIP includes raw part captures, preview renderers recoverable through its history tool, all earlier captures and both promo videos.
