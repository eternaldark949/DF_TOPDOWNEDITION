These eleven images were captured from the actual pre-conversion Canvas artists at commit `12b1158`, before replacing their draw implementations. `poses.json` contains the matching fixed input records. The references cover five feline poses and six Drone/attack states on a 320×320 opaque background.

`python tools/test-actor-art-browser.py` draws the packet versions with Chromium and compares channel differences against these originals. Small tolerance allows rasterization differences from replacing pre-baked glow/shadow sprites with equivalent gradient geometry. It also checks native frame submission without the Canvas compatibility adapter and checks that classic callers no longer invoke the old glow/shadow helpers. Requires Playwright, Chromium and Pillow. References should change only for a reviewed visual change, not merely to make a failing conversion pass.
