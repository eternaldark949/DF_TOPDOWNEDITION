# Fonts

Drop `.ttf`, `.otf`, `.woff` or `.woff2` files here. The build bakes each one into the game file
as an `@font-face`, named after the file without its extension:

| File | Use in CSS |
|---|---|
| `assets/fonts/Anthropology.ttf` | `font-family: 'Anthropology'` |
| `assets/fonts/Feminine.ttf` | `font-family: 'Feminine'` |
| `assets/fonts/Brooklyn.ttf` | `font-family: 'Brooklyn'` |
