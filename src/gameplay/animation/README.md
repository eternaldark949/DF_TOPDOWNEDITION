# Humanoid animation client

`humanoidSystem` is game policy over Basement's generic rig service. Directory installs it in `createGameRuntime`; the classic native-apartment host installs the same class. It binds actual registered Player, NPC, Ganger, Hunter and Demoness bodies. Other specialized actor artwork retains its existing pipeline. No proxy entity, per-bone body, extra clock or spatial index is introduced.

Authored proportions/builds live in `src/directory/humanoid/body-canon.json` and `builds.json`; the retained Canvas body artist reads those same tables. `getHumanoidRigAssets(gender,{build,height})` supplies immutable joint hierarchies, anchors, idle/walk clips, stance clips and initial punch/blade overlays. The root carries height/build scale; named anchors therefore match the scaled body. `humanoidPresentation(actor,blend)` requests resolved coordinates relative to that root for the existing artist, which already applies build scale.

The system selects idle/walk from actual native movement, distance synchronizes walking, selects an upper-body stance, and maps canonical weapon action progress into authored additive action clips. Basement performs interpolation, transforms, joint resolution, marker crossings and optional physical attachment placement. A game-specific `get_stance(actor)` / `get_appearance(actor)` policy can supply the initial configuration. Rig shape is fixed at binding; a future live appearance-edit operation must explicitly reconfigure its rig and mounted physical equipment together.

The native branch of `proceduralHumanoid` consumes resolved poses instead of running `stride`, `strikePose`, `placeHands`, `settle` or its old foot/knee calculations. It draws held weapons without advancing the old holster/readiness clocks or writing muzzle positions. Actual projectile origins remain owned by native combat/weapon emitters. Classic city actors continue through their original path until those callers move over.

This is the shared rig foundation and its first production client. It is not the final humanoid artwork conversion. Retained Canvas clothing, hairstyles, body shading and legacy pose catalogue still need renderer-neutral packets and authored clip conversions. The new humanoid clips cover initial idle, walking, weapon stances, punches and blade motion; they do not reproduce every previous situational gesture, weather reaction, finisher or prop-carrying pose. Existing native hair/cloth presentation remains at rest; generic Basement chains/cloth are available for its later physics port.

The rig's physical mounts use the existing attachment manager. They are prescribed mounts with optional combined mass, rather than an automatic ragdoll or a dynamic articulated skeleton. Keyframes never become the source of collision truth: actual bodies still own it.
