# Six-group migration ledger

The engine work below is implemented and exercised. **The apartment scene is cut over; the remaining scenes are pending.** See apartment scope and parity limits (game checkout: `src/directory/APARTMENT-CUTOVER.md`). Vehicle factory/taxi caller consolidation has landed in the classic client, including shared Basement path geometry. Directory definitions and scenarios are capability fixtures; they do not silently wrap, replace or migrate the old classes.

| Group | Native support added/available | Live-game work still required |
|---|---|---|
| 1. Static world, props and map lifecycle | Static/prop elements; compound billboard/building shapes; spawn-relative authored joints; exact region queries; snapshots. | Replace `StaticEntity`, `PropEntity`, every building hierarchy, billboard posts/proxies, pavement and map factories. Map data must instantiate official entities. |
| 2. Player, actors and projectiles | Character approach/braking; shared contacts and priority; projectiles/impact events; interval-based Flit placement. | Rewrite `ActorEntity`, `PlayerEntity`, `ProjectileEntity`, `TriggerEntity`, combat/ability callers and damage-only event policy. Remove game-owned projectile detection and physical response. |

| 4. | 5. | 6. Decorations, lights and effects | Separate render/light extents in one index; decoration/marker/foliage/loot/hazard definitions; particles and owned cloth meshes. | Rewrite lamps, signs, foliage, markers, loot, ghosts, hazards/effect records, visual bindings and wardrobe physics. Replace render/effect/transition grids and local visual solvers. |

`tools/test-game-physics-scenarios.mjs` exercises one Directory-based scenario per group against official engine entities. These tests are deliberately named **definitions** and do not assert that the existing game's classes use them.

`tools/audit-physics-ownership.mjs` reports remaining known legacy owners and physical API references, with optional `--json` or `--output <file>`. `--check` exits nonzero until those known remnants are gone. Rendering math, road topology and gameplay arithmetic require contextual review; an empty regex inventory alone will not prove completion.

The final cutover must connect one session world to Lobby stepping, controls, maps, saves and rendering; migrate every existing class/population; remove legacy solver and index code; and run actual game behavior/performance checks. A second body owner, writable physical mirror, wrapper around an old entity, or replacement spatial index does not count as migration.
