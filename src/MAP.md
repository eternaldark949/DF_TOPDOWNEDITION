# Source map

Every piece of *Dimensions: Freelancer (top-down)* and what lives in it. `tools/build.mjs` joins them, **in the order below**, into the playable `DFAB V8.html`.
Order matters: a file can only use, when it loads, what the files above it declared.

**The world's names.** Dimensions City has four quadrants, NDC, EDC, WDC and SDC (north, east, west, south), and the DCE (Dimensions City Epicenter) at its heart. The open city map is Southern Dimensions City, map id `sdc` (it was `hub_949`; `loadMap` and save loading still accept the old id). Other quadrants get their own ids the same way (`ndc`, `edc`, `wdc`, `dce`).

For editor/runtime batches that change static building or foliage geometry, reach, or same-length collections, call `game.invalidateRenderSpatial()` after the batch. It also invalidates effect and physics indexes. Physics-only edits can use `game.invalidatePhysicsSpatial(items)`; lamp/puddle edits within the same tick/draw can use `game.invalidateEffectSpatial()`. Map loading and known wall removal call the relevant hooks automatically.

| `world/navigation.js` | `NavGrid` pathfinding, companion tactics and steering Geometry is re-read once per simulation tick (`_refresh`). Each revision records where it changed (`_changes`), so a cached path re-plans only when a change touches its box (`pathTouched`); a goal that moves ≤32 px re-aims the path's last leg when that's clear; a failed search waits `NAV.FAIL_RETRY_TICKS`. ## buildings/
**A new landmark (or new art on one)**, so it stays cheap and is never cut off at the screen's edge:
1. Declare how far past its leaned outline it draws: `topReach` (base and roof passes), `glowReach` (glow without beams), `emissiveReach` (all glow). Without them it's still drawn correctly, just whenever it's near.
2. Run `node tools/measure-landmark-reach.cjs` (Playwright). It prints the reach each pass needs against what's declared, and fails if any needs more; declare what it needs plus a margin.
3. Paint still roof art through `PlaneSprites.draw` (`entities/prop-sprites.js`), with `PropPass.seg(live)` round anything that moves.
4. Draw a bulb (a core and its glow) as one stamp with `bulbSprite` (`core/draw-helpers.js`), not a glow plus a dot.
